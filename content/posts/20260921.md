## 이번 주 한눈에

이번 주 AI 씬의 중심에는 **GPT-6 Astra**의 현장 침투와 **에이전트 하네스(Agent Harness)** 생태계의 급팽창이 있었다. OpenAI는 법률(Astra for Law), 데이터 분석(Hex), 검색(Perplexity) 등 다양한 버티컬에 GPT-6 Astra를 적용한 파트너 사례를 잇달아 공개하며 엔터프라이즈 시장 공략을 가속화했다. 동시에 GitHub에서는 Claude Code·Codex·Cursor를 아우르는 에이전트 하네스·스킬 관련 오픈소스 저장소가 트렌딩 상위권을 휩쓸었다.

한편 AI 안전성 논의도 뜨거웠다. OpenAI의 모델 미정렬 보고 프레임워크 공개, ZCode의 무단 Git 히스토리 업로드 폭로, AI 업계의 속도 조절 가능성에 대한 회의론 등 신뢰와 거버넌스 문제가 여러 채널에서 동시에 터져 나왔다. Anthropic은 생명과학 검증 프로그램과 Accenture 협력을 통해 평가 체계를 강화하는 방향으로 대응했다.

## 주제별 분석

#### 🚀 GPT-6 Astra의 엔터프라이즈 확산

OpenAI는 GPT-6 Astra 기반 파트너 사례를 대거 공개했다. 법무법인 Cooley는 [GO Public](https://openai.com/index/cooley-gopublic)으로 IPO 서류 검토를 자동화했고, [Astra for Law](https://openai.com/index/astra-for-law)는 기밀 클라이언트 데이터를 위한 법률 전용 제어 기능을 탑재했다. [Hex](https://openai.com/index/hex-gpt-6-astra)는 데이터 분석 결과를 인터랙티브 시각화 보고서로 전환하는 데 Astra를 활용하고, [Perplexity](https://openai.com/index/perplexity-improving-accuracy-with-astra)는 소프트웨어 수정·프로덕션 모니터링까지 Astra에 위임하며 개입 빈도를 크게 줄였다고 밝혔다. 광고 분야에서는 [Sponsored Agents·HubSpot·Shopify 통합](https://openai.com/index/reimagining-advertising-with-ai) 등 새로운 수익 모델도 제시됐다. 한편 TLDR AI는 *Databricks의 Astra 도입 비용이 +60%에 달한다*는 [현실 점검 기사](https://www.latent.space/p/ainews-reality-checks-on-ai-news)를 통해 비용 문제도 환기시켰다.

#### 🛡️ AI 안전성·윤리·거버넌스

OpenAI는 [모델 미정렬 보고 프레임워크](https://openai.com/index/model-misalignment-reporting-framework)를 공개하며 예상치 못한 모델 행동 6건을 함께 공시했다. Anthropic은 [생명과학 검증 프로그램](https://www.anthropic.com/news/life-sciences-verification-program)을 출범시키고 [Accenture와 임베디드 평가 파트너십](https://www.anthropic.com/news/accenture-embedded-evaluation)을 맺었다. Hacker News에서는 [ZCode 코딩 에이전트가 Git 히스토리를 무단 업로드](https://tokenstead.ai/guides/zcode-silent-git-history-upload)한다는 폭로가 261포인트를 기록하며 큰 파장을 일으켰다. TechCrunch는 [AI 안전 담론이 허구와 사실을 구분하기 어려운 지경에 이르렀다](https://techcrunch.com/2026/09/19/ai-safety-conversations-have-gotten-unbelievable/)고 진단했고, Simon Willison이 인용한 [현장 개발자 증언](https://simonwillison.net/2026/Sep/20/voxium/)은 Claude Code 강제 도입에 대한 실무자의 불만을 날것으로 보여줬다. Bluesky에서는 AI 스크래핑을 "역사상 최대 노동 착취"로 규정한 Microsoft 임원 발언이 Ian Goodfellow 등을 중심으로 빠르게 확산됐다.

#### 🤖 에이전트 하네스·코딩 에이전트 오픈소스 붐

GitHub 트렌딩은 사실상 에이전트 인프라 프로젝트들의 축제였다. [anthropics/claude-code](https://github.com/anthropics/claude-code), [alibaba/open-code-review](https://github.com/alibaba/open-code-review), [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills), [affaan-m/ECC](https://github.com/affaan-m/ECC) 등 코딩 에이전트 역량을 극대화하는 하네스·스킬 레포지토리가 상위권을 점령했다. Cline은 이번 주에만 Desktop v0.0.29~v0.0.32를 연속 출시하며 SSH 원격 작업, 이미지 미지원 모델 경고, Windows 업데이트 버그 수정 등을 빠르게 반영했다([v0.0.31](https://github.com/cline/cline/releases/tag/desktop-v0.0.31) 참조). Latent Space는 [Jev](https://www.latent.space/p/ainews-jev-a-system-one-model-that)라는 "System One Model"—소형 프론티어 LLM 대비 100배 빠르고 200배 저렴한 분류·라우팅 전용 모델—을 집중 조명했고, 이틀 만에 6개의 클론이 등장했다고 보도했다([AINews](https://www.latent.space/p/ainews-here-are-6-clones-of-jev-in)).

#### 🌍 AI의 사회적 확장: 포용성·경제·규제

OpenAI는 [AARP와 협력해 미국 10개 도시 고령층 1,000명에게 ChatGPT 워크숍을 무료 제공](https://openai.com/index/helping-older-adults-use-ai-in-everyday-life)하고, [호주 청소년 안전 블루프린트](https://openai.com/index/australian-youth-safety-blueprint)를 발표하는 등 포용적 AI 확산에 힘을 쏟았다. Google은 [AI & Economy ATLAS v1.0](https://blog.google/innovation-and-ai/technology/ai/ai-economy-atlas-september-2026/)을 통해 AI와 경제의 상관관계 데이터를 공개하고, [UN Data Commons 플랫폼](https://blog.google/innovation-and-ai/technology/ai/google-un-data-commons-platform/)으로 글로벌 데이터 접근성을 높였다. TechCrunch는 [월드 모델 기업들이 투자금은 넘치지만 실제 개발 내용은 철저히 비밀에 부친다](https://techcrunch.com/2026/09/20/world-model-companies-are-keeping-a-lot-of-secrets/)고 꼬집었으며, Vals AI가 [a16z 지원을 받아 AI 벤치마킹의 표준이 되겠다고 선언](https://techcrunch.com/2026/09/19/vals-backed-by-andreessen-horowitz-is-looking-to-become-the-gold-standard-for-ai-benchmarking/)한 것도 주목할 만한 소식이었다.
