## 한 줄로 말하면

Anthropic(앤스로픽, AI 연구 회사)이 Claude Opus 5를 출시했습니다. 최상위 모델인 Fable 5에 근접한 성능을 내면서도 가격은 절반 수준이고, 코딩·지식 업무·과학 연구 전반에서 전작(Opus 4.8)을 크게 앞섭니다.

---

## 왜 중요해요

AI 모델은 보통 "성능이 높으면 비용도 높다"는 트레이드오프(trade-off, 한쪽을 얻으면 다른 쪽을 잃는 관계)가 있습니다. Opus 5는 이 공식을 깨는 사례입니다.

- **가격 대비 성능**: Fable 5(최고 성능 모델)의 절반 비용으로 거의 같은 수준의 결과를 냅니다.
- **일상적인 사용에 최적화**: Claude Max의 새로운 기본(default) 모델로 지정될 만큼 실용성을 강조합니다.
- **에이전트(agent, 스스로 판단하고 행동하는 AI) 작업에 강함**: 단순 질답을 넘어, 긴 시간 동안 여러 단계의 작업을 자율적으로 수행하는 데 특화되어 있습니다.

기업 입장에서는 비용 부담 없이 고성능 AI를 실무에 투입할 수 있게 된다는 점에서, 이번 출시는 업계 전반에 영향을 줄 수 있는 변화입니다.

## 자세히

### 📊 주요 벤치마크(benchmark, 성능 측정 기준) 성과

원문에 언급된 평가 결과를 구체적으로 살펴보면 다음과 같습니다.

| 평가 항목 | 결과 |
|---|---|
| **Frontier-Bench v0.1** (소프트웨어 엔지니어링) | 모든 모델 중 1위, Opus 4.8 대비 성능 2배 이상·더 낮은 비용 |
| **CursorBench 3.2** (코딩) | 최대 노력(max effort) 설정 시 Fable 5 최고 점수와 0.5% 차이, 비용은 절반 |
| **ARC-AGI 3** (새로운 문제 해결) | 차순위 모델보다 점수가 **3배** 높음 |
| **Zapier AutomationBench** (비즈니스 자동화) | 동일 비용 대비 합격률이 차순위 모델의 **약 1.5배** |
| **OSWorld 2.0** (컴퓨터 직접 사용) | Fable 5 최고 결과를 **약 1/3 비용**으로 초과 달성 |

### 🔬 과학 연구 분야

생명과학(structural biology·organic chemistry·bioinformatics 등) 평가 전 항목에서 Opus 4.8을 앞섰습니다.
- **유기화학** (분광학 데이터로 분자 구조 추론): Opus 4.8 대비 **+10.2%p**
- **단백질 연구** (서열 변이가 기능에 미치는 영향 예측): Opus 4.8 대비 **+7.7%p**

### 🤖 실제 에이전트 작업 사례

원문에 소개된 대표적인 실사용 사례들입니다.

1. **3D 모델 재현**: 기계 부품 도면을 주고 FreeCAD(3D 모델링 소프트웨어) 코드 작성을 요청했을 때, 도면을 직접 볼 수 없는 상황에서도 자체 컴퓨터 비전(computer vision, 이미지 분석 기술) 파이프라인을 만들어 기계 부품 재현에 성공했습니다. 경쟁 모델은 같은 조건에서 5번 시도 후에도 실패했습니다.
2. **오픈소스 버그 수정**: 널리 쓰이는 오픈소스 패키지 매니저의 버그를 분석했을 때, 커뮤니티 패치가 놓친 엣지 케이스(edge case, 예외 상황)까지 찾아 근본 원인을 해결했습니다.
3. **거래소 데이터 피드 구축**: 트레이딩 회사의 엔지니어가 단 한 세션 만에 새로운 거래소용 시장 데이터 피드를 완성했으며, 이전 모델들은 상세한 계획서를 줘도 완료하지 못했던 작업입니다.

### 💼 기업 고객 사용 후기 (원문 인용 기반)

원문에는 다양한 기업의 실사용 사례가 소개되어 있습니다.

- **Box**: Opus 4.8 대비 전반 **+8%**, 데이터 분석 **+11%**, 실사조사(due diligence) **+17%** 향상
- **금융 모델링**: Opus 4.8 대비 평균 정확도 **+9%p**, 소요 턴(turn, 대화 횟수) **1/3 감소**, 처리 시간 **60% 단축**
- **Lovable (개발 플랫폼)**: 가장 어려운 에이전트 코딩 작업에서 Opus 4.7 대비 **+22%**, 결과 변동성도 크게 줄어 안정성 향상
- **유전체학(genomics) 분석**: 통계 검정 선택, 결과 교차 검증 등 "신중한 과학자처럼" 행동한다는 평가

### ⚙️ 노력 설정(effort setting) 기능

Opus 5는 **노력 설정** 기능을 통해 지능 수준과 속도·비용 사이의 균형을 사용자가 직접 조절할 수 있습니다. 낮은 설정에서도 다른 모델의 최대 설정보다 뛰어난 결과를 내는 경우가 있다고 원문은 설명합니다.
