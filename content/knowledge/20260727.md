## 한 줄로 말하면

LLM(대형 언어 모델, Large Language Model) API 토큰을 싸게 재판매하는 '릴레이 마켓(Relay Market)'이라는 지하 생태계가 성장하고 있으며, 이는 개발자와 LLM 서비스 제공자 모두에게 심각한 보안 위협이 되고 있다.

---

## 왜 중요해요

LLM API를 사용하면 사용량만큼 비용이 청구된다. 그런데 이 비용을 비정상적인 방법으로 줄여 싸게 재판매하는 시장이 생겨났다. 문제는 이 시장이 단순한 '절약' 수준을 넘어, 무방비 상태의 API 엔드포인트(endpoint, 외부에서 접근 가능한 서버 주소)를 찾아 착취하는 데서 이익을 얻는 **전문적인 생태계**로 발전했다는 점이다. 내 앱이 공격 대상이 되면 예상치 못한 엄청난 청구서를 받을 수 있다.

---

## 자세히

### 릴레이 마켓이란?

릴레이 마켓은 LLM API 토큰을 정가보다 훨씬 싸게 재판매하는 시장이다. 주로 중국에서 활발하게 운영되는 것으로 알려져 있다.

재판매자들은 **프록시(proxy, 중간 대리 서버)**를 통해 LLM API 접근권을 고객에게 제공하는데, 이 할인된 가격은 다음과 같은 방법으로 만들어진다.

- **무료 체험(Free Trial) 악용**: 여러 계정의 무료 체험 API 키를 모아 돌려쓴다.
- **보호되지 않은 지원 봇 경유**: 외부에 노출된 고객 지원용 챗봇 등을 통해 몰래 요청을 보낸다.
- **도난 신용카드 또는 차지백(Chargeback, 신용카드 결제 취소 공격) 악용**: 결제 수단 자체를 부정하게 사용한다.

### 어떤 소프트웨어를 쓰나?

이 프록시들은 오픈소스 소프트웨어를 기반으로 한다. 주로 사용되는 것은 **one-api**와 그 후속 프로젝트인 **new-api**로, 원래는 여러 API 자격증명(credential)의 요청을 분산시키는 로드 밸런싱(load balancing) 용도의 합법적인 도구다. 그러나 이 도구들이 부정한 API 키 풀(pool)을 관리하는 데 그대로 활용되고 있다.

### 구매자들의 목적은?

- 저렴한 토큰 비용
- 지역 제한(geo-restriction) 우회
- 일부의 경우, 모델 디스틸레이션(distillation, 대형 모델의 출력을 학습 데이터로 삼아 소형 모델을 훈련하는 기법)을 위한 데이터 수집

### 개발자에게 주는 시사점

Simon Willison은 자신도 LLM 기반 앱을 공개적으로 배포하는 것에 이미 조심스러웠다고 밝힌다. 이 릴레이 마켓의 존재는 그 우려를 더욱 키운다. **새로운 무방비 엔드포인트를 발견하는 것 자체가 이익이 되는 생태계**가 형성됐기 때문이다.

그는 LLM 벤더(vendor, 서비스 제공사)들이 API 키에 **엄격한 사용 한도(strict cap)**를 설정할 수 있도록 기능을 개선해야 한다고 강조한다. 특정 금액 임계값에 도달하는 즉시 앱이 멈추는 기능이 필요하다는 것이다.
