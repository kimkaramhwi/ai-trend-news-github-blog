## 한 줄로 말하면

ChatGPT Work는 그냥 대화하는 ChatGPT Chat과 달리, **인터넷에 연결된 코드 실행, 브라우저 조작, 파일 저장, 웹사이트 배포, 자동화**까지 가능한 '작업 완수형' AI 도구입니다.

---

## 왜 중요해요

ChatGPT는 그동안 "답을 알려주는" 도구였다면, ChatGPT Work는 **직접 일을 해주는** 도구로 진화한 것입니다. 예를 들어 "이 GitHub 저장소를 받아서 실행하고 결과를 정리해줘"라고 하면, Work는 실제로 그걸 해냅니다. Chat은 할 수 없는 일이죠.

또한 단순한 한 번의 대화가 아니라, 매일 정해진 시간에 자동으로 검색하고 알림을 보내는 **예약 자동화**도 가능해졌습니다. AI가 단순 보조 도구를 넘어 **자율적으로 작업을 수행하는 에이전트(agent, 스스로 판단하고 행동하는 AI)** 에 가까워지고 있다는 점에서 주목할 만합니다.

---

## 자세히

### ChatGPT Work는 사실 두 가지 제품입니다

Simon Willison의 분석에 따르면, ChatGPT Work는 실제로 두 가지로 나뉩니다.

- **Work Cloud**: chatgpt.com이나 모바일 앱에서 접근하는 클라우드 기반 버전
- **Work Local**: ChatGPT 데스크톱 앱(이전에 Codex라고 불리던 앱)을 설치했을 때 접근할 수 있는 버전. 내 컴퓨터의 파일에 직접 접근하거나 프로그램을 실행할 수 있습니다.

이 글에서는 **Work Cloud** 위주로 다룹니다.

---

### 누가 쓸 수 있나요?

ChatGPT Work는 현재 **월 $20 이상 유료 구독자 전용**입니다. 무료 사용자나 월 $8짜리 Go 플랜 사용자는 접근할 수 없습니다.

---

### Chat vs Work, 뭐가 다를까요?

OpenAI의 공식 설명은 이렇습니다.

> "답변, 설명, 브레인스토밍, 짧은 초안이 필요하면 Chat을 쓰세요. 명확한 결과물이 있는 작업(보고서, 분석, 반복 업데이트, 워크플로우, 파일 등)을 완수하고 싶다면 Work를 쓰세요."

하지만 저자는 이 설명만으론 부족하다고 지적하며, **Work에만 있는 기능**들을 직접 실험을 통해 정리했습니다.

---

### Work Cloud에만 있는 핵심 기능들

#### 1. 🌐 인터넷이 연결된 코드 실행 환경
기존 ChatGPT Chat의 코드 실행(Code Interpreter, 코드 인터프리터)은 외부 인터넷 접근이 막혀 있었습니다. 하지만 **Work Cloud는 인터넷에 열려 있어**, GitHub 저장소를 직접 받아오거나, 외부 API를 호출하거나, 추가 소프트웨어 패키지를 설치하는 것이 가능합니다. 접근 가능한 도메인 목록을 따로 설정할 수도 있고, 기본값은 전체 열림 상태입니다.

참고로 Claude(경쟁 AI 서비스)도 비슷한 컨테이너 환경을 제공하지만, 접근 가능한 도메인 허용 목록이 매우 짧다고 저자는 비교했습니다.

#### 2. 🖥️ 헤드리스 크롬 브라우저 (Headless Chrome)
헤드리스 브라우저(headless browser)란 화면에 보이지 않는 상태로 웹사이트를 여는 도구입니다. Work는 실제 Chrome 브라우저 인스턴스를 실행해서 웹사이트를 불러오고, 폼을 채우고, 스크린샷을 찍을 수 있습니다.

로그인이 필요한 사이트는 사용자가 직접 비밀번호와 2단계 인증 코드를 입력하도록 제어권을 넘겨주는 방식으로 보안도 챙겼습니다(비밀번호 자체가 AI 모델을 통과하지 않음). JavaScript(자바스크립트, 웹페이지를 동적으로 제어하는 프로그래밍 언어)로 페이지의 내용을 추출하는 것도 가능합니다.

#### 3. 💾 세션 간 공유되는 영구 파일 시스템
Chat은 대화가 끝나면 파일이 사라집니다. 반면 Work는 각 세션에 전용 폴더가 생기고, **이 파일들이 이후 세션에서도 유지됩니다**. 저자의 경우 현재 171개의 폴더가 쌓여 있다고 합니다. 동시에 실행 중인 여러 Work 세션에서 이 파일들을 함께 볼 수도 있습니다.

#### 4. 🌍 ChatGPT Sites (웹사이트 빌드 & 배포)
Work를 통해 완전한 웹사이트를 만들고 배포할 수 있습니다. Cloudflare Workers(클라우드플레어 워커스, 서버 없이 코드를 실행할 수 있는 플랫폼) 기반으로 HTML, JavaScript는 물론 서버 기능과 데이터 저장까지 지원합니다.

저자는 "런던에서 '경건한 펠리컨' 문양이 있는 장소를 모두 찾아 JSON 파일로 만들고 사이트를 만들어줘"라고 입력해서 실제로 사이트를 만들었다고 소개했습니다. 기본적으로 본인만 볼 수 있는 비공개 설정이며, 원하면 공개하거나 특정 사람과 공유할 수 있습니다.

#### 5. 🤖 서브 에이전트 실행 (Sol, Luna, Terra)
복잡한 프로젝트에서 여러 에이전트가 병렬로 함께 작업하도록 시킬 수 있습니다. Chat에는 없는 기능입니다. 모델 선택도 Work에서는 GPT-5.6 Sol, Luna, Terra 중에서 고를 수 있으며 추론 수준도 Light부터 Ultra까지 세분화되어 있습니다.

#### 6. ⏰ 예약 자동화 프롬프트
"매일 오전 8시에 Waymo가 Half Moon Bay 출시일을 발표했는지 검색해줘"처럼 입력하면, 해당 주기로 자동으로 실행됩니다. 새로운 정보가 있을 때만 알림을 보내도록 설정할 수도 있습니다.
