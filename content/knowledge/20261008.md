## 한 줄로 말하면

Anthropic이 새 경량 모델 **Claude Haiku 5.5**를 출시했습니다. 경쟁 모델과 같은 가격대로 맞췄고, 구독자에게는 매달 API 크레딧도 지급합니다.

---

## 왜 중요해요

경량 모델(light model, 응답 속도가 빠르고 비용이 낮은 AI 모델)은 실제 서비스에서 가장 많이 쓰이는 유형입니다. Haiku 5.5는 이전 버전인 Haiku 4.5보다 훨씬 저렴해졌고, 벤치마크(benchmark, 모델 성능을 비교하는 표준 시험) 점수도 높다고 알려져 있습니다. 개발자 입장에서는 "어떤 모델을 기본값으로 쓸 것인가"를 결정할 때 직접적인 영향을 받습니다.

---

## 자세히

### 가격 변화

| 항목 | Haiku 4.5 | Haiku 5.5 |
|---|---|---|
| 입력(input) 가격 | $1 / 100만 토큰 | $0.10 / 100만 토큰 (100K 토큰 이하) |
| 출력(output) 가격 | $5 / 100만 토큰 | $0.50 / 100만 토큰 (100K 토큰 이하) |

100,000 토큰을 초과하면 가격이 5배 올라 입력 $0.50, 출력 $2.50이 됩니다. 이 구간에서는 OpenAI의 GPT-6 Luna가 더 유리하다고 글쓴이는 평가합니다.

### 숨겨진 비용: 새 토크나이저

글쓴이가 직접 만든 **Claude Token Counter** 도구로 측정한 결과, 같은 긴 프롬프트를 입력했을 때 Haiku 5.5가 Haiku 4.5보다 **약 1.25배 더 많은 토큰(token, AI가 텍스트를 처리하는 최소 단위)**을 사용했습니다. 명목 가격은 내려갔지만, 토크나이저(tokenizer, 텍스트를 토큰으로 쪼개는 방식) 변경으로 실질 비용이 일부 상쇄됩니다.

### 추론(Reasoning) 기본 탑재

Haiku 5.5는 추론(reasoning, 모델이 답을 내기 전에 단계적으로 생각하는 기능)을 끌 수 없으며, 기본값은 **medium** 수준입니다. 글쓴이는 low·medium·high·xhigh·max 다섯 단계로 펠리컨 그림을 생성하는 테스트를 진행했습니다.

- **low 수준** 펠리컨: 0.0936센트, 7초 소요
- **max 수준** 펠리컨: 3.3826센트, 5분 9초 소요
- 반면 Haiku 4.5(추론 미지원)가 그린 펠리컨은 0.7583센트였으나 품질이 낮았다고 평가합니다.

### 구독자 API 크레딧 혜택

Anthropic은 Haiku 5.5 출시와 함께 **Max·Team 구독자**에게 매달 API 크레딧을 지급한다고 발표했습니다.

- **Max 5x** 구독자: 월 $100 크레딧
- **Max 20x** 구독자: 월 $200 크레딧
- **Team** 구독자: 사용자 풀(pool) 합산 최대 월 $500 크레딧

크레딧 금액은 구독료와 동일한 수준이며, 설정에서 자동 충전을 끄면 잔액 소진 시 API 요청이 중단되어 예상치 못한 과금을 막을 수 있습니다. 단, **크레딧은 매월 이월되지 않으므로** 그달 안에 사용해야 합니다.

또한 이날 Anthropic은 **Sonnet 5.5의 캐시 읽기(cache read) 비용을 절반으로 인하**한다고 함께 발표했습니다.
